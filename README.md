# Student Placement Management System

A Java Swing and MySQL-based desktop application designed to manage student placement activities efficiently.

## Features

- Admin Login
- Dashboard with placement statistics
- Manage Student Records
- Manage Company Records
- Check Student Eligibility
- Manage Placement Applications
- Track Application Status
- Placement Reports
- Prevent Duplicate Applications

## Technologies Used

- Java
- Java Swing
- JDBC
- MySQL
- Git and GitHub

## Project Structure

- `gui/` - Graphical user interface
- `dao/` - Database operations
- `database/` - Database connection
- `model/` - Data models
- `lib/` - External libraries
- `Main.java` - Application entry point

## Database

The application uses MySQL to store student, company, and application records.

Create a database named `placement_db` and configure the database connection before running the application.

## How to Run

1. Install Java JDK.
2. Install MySQL Server and MySQL Workbench.
3. Configure the database connection.
4. Open the project in Visual Studio Code.
5. Configure the required libraries.
6. Run `Main.java`.
